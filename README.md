# Airdown

**The trip HQ for crews who leave pavement.**

Plan it, pin it, hand it to onX. Built from a real Calgary→Utah→Vegas overland loop — then productized.

This repo is the **public story** only (marketing + waitlist). The product codebase stays private.

## What it is
- **Build** — tap-first trip intake
- **Trip HQ** — day cards, honesty-tagged pins, schematic route
- **Handoff** — one-tap GPX for onX / Gaia (waypoints with source + confidence)

We never invent campsite availability. Every pin carries SOURCE · CONFIDENCE.

## Status
Concierge MVP — book a trip build. Selling a few stranger trips before scaling.
